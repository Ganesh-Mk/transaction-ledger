# Ledger web console

React + Vite + TypeScript + Tailwind v4 single-page app for the Transaction Ledger API.
See the [root README](../README.md) for setup.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api and /health to localhost:8080
npm run build    # static bundle in dist/ (set VITE_API_URL to the API origin)
```
